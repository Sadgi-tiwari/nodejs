Exercise 1: Database Selection
Choose the appropriate database type (SQL/NoSQL) and justify:
1. Online Banking System → SQL
Requires strict ACID properties to ensure secure and accurate financial transactions. 
Structured schema helps maintain consistency and integrity of data.

2. Social Media Platform → NoSQL
Handles **large-scale, unstructured data** like posts and media.
 Provides high scalability and flexible schema for dynamic content.

3. Real-time Chat Application → NoSQL
Needs fast read/write operations and real-time data handling.
 NoSQL supports high concurrency and quick message delivery.

4. Hospital Patient Records → SQL
Requires high accuracy and consistency for sensitive medical data.
 Structured schema supports complex queries and relationships.

5. IoT Sensor Data Collection → NoSQL
Deals with massive, continuous data streams from sensors. 
NoSQL offers high scalability and efficient data ingestion.

Exercise 2: CAP Theorem Analysis
For each scenario, identify which CAP properties are prioritized:
1. Stock Trading Platform → CP 
Consistency is critical to ensure correct stock prices and transactions. 
Even during network issues, the system prioritizes accurate data over availability.

2. Content Delivery Network (CDN) → AP 
CDNs must always be available to serve content quickly. 
Slight inconsistencies are acceptable for better performance and uptime.

3. Airline Booking System → CP 
Consistency is essential to avoid double booking of seats.
 System may sacrifice availability during failures to maintain correct data.

4. Video Streaming Service → AP
High availability is required for uninterrupted streaming. 
Temporary inconsistencies are acceptable.

Assessment Questions:
1. Explain the key differences between SQL and NoSQL databases with examples.
SQL databases are best when you need structured data, strong consistency, and complex queries.
NoSQL databases are better for flexibility, scalability, and handling large or unstructured data.

2. What does the CAP theorem state, and why can’t a distributed system guarantee all three
properties?

The CAP theorem states that a distributed system can guarantee only two out of three  properties:

Consistency (C): All users see the same latest data
Availability (A):Every request gets a response
Partition Tolerance (P): System works despite network failures

During a network failure (partition), the system must choose:

Consistency (CP) → may reject requests (less available)
Availability (AP) → may return outdated data (less consistent)

3. Describe three scenarios where MongoDB would be preferred over a relational database.
MongoDB is preferred when:

1. Flexible schema → Data structure changes frequently
2. Big data & scalability → Handles large data using horizontal scaling
3. Real-time apps → Fast read/write (e.g., chat, notifications)

4. Why does MongoDB use BSON internally instead of storing documents as JSON?

MongoDB uses BSON instead of JSON because:

1. Faster processing → Binary format is quicker to read/write
2.More data types → Supports Date, ObjectId, Binary, etc. (JSON doesn’t)
3.Efficient storage → Compact and optimized for performance
4.Indexing support → Easier and faster indexing internally

Exercise 4: Aggregation
Create aggregation pipelines to:
1. Calculate average GPA by department:-
db.students.aggregate([
  { $group: { _id: "$department", avgGPA: { $avg: "$GPA" } } }
])
2. Find most popular courses:-
db.students.aggregate([
  { $unwind: "$courses" },
  { $group: { _id: "$courses", count: { $sum: 1 } } },
  { $sort: { count: -1 } }
])
3. Generate student performance report:-
db.students.aggregate([
  {
    $group: {
      _id: "$department",
      avg: { $avg: "$GPA" },
      max: { $max: "$GPA" },
      min: { $min: "$GPA" }
    }
  }
])

Assessment Questions

1. What are the advantages of using Mongoose over the native MongoDB driver?
Mongoose makes MongoDB easier by adding schema, validation, and structured data handling.

2. Explain the difference between findOneAndUpdate() and updateOne().
findOneAndUpdate() returns the document after update, while updateOne() only updates and returns status.

3. What is the purpose of middleware in Mongoose?
Middleware is used to execute functions before or after database operations automatically.

4. How do you implement pagination in Mongoose?
Pagination in Mongoose is implemented using skip() and limit() to fetch data page by page.

5. When should you use embedding vs referencing in MongoDB schema design?
Use embedding for closely related small data, and referencing for large or shared data.
